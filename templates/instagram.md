# Instagram Caption Template

Length: 100-200 words. First line is the hook (visible in feed).

## Structure

1. **Hook** (1 line). Specific number or one strong tension.
2. **Body** (5-8 short lines or bullets). Visual rhythm matters more than length.
3. **Insight pivot**. One short sentence that lands.
4. **CTA**. From brief.
5. **Hashtags**. 8-12, mix of niche + broad. End of caption.

## Hard rules

- Use line breaks generously — IG eats whitespace.
- Match `tone.primary` from brief.
- End with default CTA from brief.
- Avoid anti-topics from brief.
- Use `language` from brief.
- Hashtags should be relevant, NOT spammy. Mix audience-targeting + topic-targeting.

## Variables

- `{{title}}` — for dashboard only
- `{{content}}` — caption body
- `{{hashtags}}` — array of 8-12 hashtags
- `{{schedule_suggestion}}` — e.g. "Wednesday 18:00 CET"
- `{{word_count}}` — auto-calculated
