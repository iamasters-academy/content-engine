# YouTube Short Script Template

Duration: 45-60 seconds. Vertical 9:16. Spoken script, NOT a written caption.

## Structure (with timestamps)

- **0:00-0:03 — Hook** (3s). The strongest line. Has to make people NOT swipe.
- **0:03-0:10 — Promise** (7s). What they'll get if they stay.
- **0:10-0:35 — Body** (25s). The story or the steps. Concrete.
- **0:35-0:50 — Punchline** (15s). The "ahá".
- **0:50-0:60 — CTA** (10s). From brief, plus "follow for more".

## Hard rules

- WRITE FOR SPOKEN. Short sentences. Cut every word that doesn't add.
- Estimate ~2.5 words per second of speech.
- Add `[B-roll: ...]` hints for visual cues.
- Add `[Cut]` markers between scenes.
- Match `tone.primary` from brief.
- Use `language` from brief.

## Variables

- `{{script}}` — the actual script with timestamps
- `{{title_suggestion}}` — punchy title (60 chars max)
- `{{description}}` — 1-2 lines for the YouTube description box
- `{{tags}}` — 5-10 SEO tags
- `{{thumbnail_idea}}` — text suggestion for the cover frame
